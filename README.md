# Desafios

Desafios de lógica de programação resolvidos em Python.

| Desafio | Pasta |
|---|---|
| Fechem as portas! | [fechem_as_portas](fechem_as_portas) |
| Esquerda, Volver! | [esquerda_volver](esquerda_volver) |
| Suco de Acerola | [suco_de_acerola](suco_de_acerola) |
| Help! | [help](help) |

Cada pasta contém:
- `entrada.txt`: exemplo de entrada;
- `saida.txt`: saída esperada para essa entrada;
- `nome_desafio.py`: a solução;
- `README.md`: a descrição do desafio.

## Como executar
Dentro da pasta de um desafio, em qualquer terminal (PowerShell, CMD ou Bash):
```
python nome_desafio.py
```
O programa lê sozinho o `entrada.txt` da pasta dele.

Para testar todos os desafios de uma vez, na pasta `desafios`:
```
python testar.py
```
Ele roda cada programa e compara o resultado com o `saida.txt`.
